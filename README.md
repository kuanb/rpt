# Rose Park Terrace HOA Content

Static analysis and reference pages for Rose Park Terrace.

The built site is intended to publish at `https://kuanbutts.com/rpt/`, with dated pages under paths like:

```text
https://kuanbutts.com/rpt/YYYY/MM/DD/file-name/
```

## Adding A Page

Add each generated HTML page as an `index.html` file under `content/YYYY/MM/DD/slug/`.

For example:

```text
content/2026/07/17/reserve-analysis/index.html
```

The GitHub Pages workflow copies `content/` into the published site and regenerates the root index automatically.
